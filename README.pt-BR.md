**OrderFlow** é uma aplicação full stack de gerenciamento de pedidos desenvolvida para demonstrar conhecimentos práticos de backend e engenharia de software além de aplicações CRUD básicas.

O projeto combina um **frontend em React + TypeScript** com um **backend em FastAPI**, PostgreSQL, Redis, Celery, Stripe em Test Mode, Docker, testes automatizados, CI/CD, análise de segurança e infraestrutura com características de ambiente de produção.

<a href="https://github.com/Jos3Vitor34/orderflow">
  <img src="https://raw.githubusercontent.com/Jos3Vitor34/orderflow/main/docs/assets/dashboard.png" alt="Dashboard do OrderFlow" />
</a>

### Arquitetura & Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, Axios, React Hook Form e Zod.
- **Backend:** Python 3.12+, FastAPI, Pydantic, SQLAlchemy 2, Alembic e Uvicorn.
- **Banco de dados:** PostgreSQL com operações transacionais e controle de concorrência de estoque.
- **Autenticação:** fluxo OAuth2 Password, JWT, hashing de senhas com Argon2 e RBAC.
- **Processamento em background:** Redis e Celery com retries e correlation IDs.
- **Pagamentos:** Stripe Payment Intents, reembolsos, idempotência e webhooks assinados em Test Mode.
- **Infraestrutura:** Docker, Docker Compose, Nginx, verificações de health/readiness, migrations, volumes persistentes e TLS opcional.
- **Observabilidade:** logs estruturados em JSON e correlation IDs.
- **CI/CD:** GitHub Actions com pipelines automatizados de qualidade e segurança.

### Principais Funcionalidades

- Gerenciamento de clientes e produtos.
- Criação e gerenciamento do ciclo de vida de pedidos.
- Controle transacional de estoque.
- Gerenciamento de pagamentos e reembolsos.
- Sincronização por webhooks da Stripe.
- Autenticação JWT e autorização baseada em papéis.
- Administração de usuários.
- Dashboard com estatísticas operacionais.
- Tarefas assíncronas em background.
- Interface responsiva com suporte a **pt-BR e inglês**.
- Ambiente full stack executado com Docker.
- Documentação interativa OpenAPI/Swagger.

### Testes & Segurança

- **439 testes de backend**

- **457 testes automatizados no total**
