## 🚀 Featured Project — OrderFlow API

OrderFlow is a Python backend API for order and payment management, built to demonstrate practical backend engineering: domain modeling, transactional persistence, authorization, asynchronous processing, and security controls.

- **API:** Python 3.12, FastAPI, Pydantic, SQLAlchemy 2, and Uvicorn.
- **Database and migrations:** PostgreSQL 17, psycopg 3, and Alembic.
- **Background jobs:** Redis 8 and Celery 5.6 for asynchronous tasks and retries.
- **Authentication and access control:** OAuth2 password flow, JWT, Argon2 password hashing, and role-based access control (RBAC).
- **Payments:** Stripe Payment Intents, refunds, idempotency, and signed webhooks in Test Mode.
- **Operations:** Docker, Docker Compose, structured JSON logs, correlation IDs, and health/readiness endpoints.
- **Quality and security:** pytest, coverage, Ruff, mypy, pip-audit, Gitleaks, Trivy, and GitHub Actions workflows.

The API includes Customers, Products, Orders, Payments, Refunds, inventory-aware order transitions, user administration, and aggregate statistics. The local Docker Compose stack runs PostgreSQL, Redis, database migrations, the API, and a Celery worker. Interactive API documentation is available through OpenAPI/Swagger.

🔗 [View the OrderFlow repository](https://github.com/Jos3Vitor34/orderflow)
