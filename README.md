**OrderFlow** is a full-stack order management application built to demonstrate practical backend and software engineering beyond basic CRUD applications.

It combines a **React + TypeScript frontend** with a **FastAPI backend**, PostgreSQL, Redis, Celery, Stripe Test Mode, Docker, automated testing, CI/CD, security scanning, and production-style infrastructure.

<a href="https://github.com/Jos3Vitor34/orderflow">
  <img src="https://raw.githubusercontent.com/Jos3Vitor34/orderflow/main/docs/assets/dashboard.png" alt="OrderFlow Dashboard" />
</a>

### Architecture & Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, Axios, React Hook Form, and Zod.
- **Backend:** Python 3.12+, FastAPI, Pydantic, SQLAlchemy 2, Alembic, and Uvicorn.
- **Database:** PostgreSQL with transactional operations and inventory locking.
- **Authentication:** OAuth2 password flow, JWT, Argon2 password hashing, and RBAC.
- **Background processing:** Redis and Celery with retries and correlation IDs.
- **Payments:** Stripe Payment Intents, refunds, idempotency, and signed webhooks in Test Mode.
- **Infrastructure:** Docker, Docker Compose, Nginx, health/readiness checks, migrations, persistent volumes, and optional TLS.
- **Observability:** structured JSON logging and correlation IDs.
- **CI/CD:** GitHub Actions with automated quality and security pipelines.

### Main Features

- Customer and product management.
- Order creation and lifecycle management.
- Transactional inventory control.
- Payment and refund management.
- Stripe webhook synchronization.
- JWT authentication and role-based authorization.
- User administration.
- Dashboard with operational statistics.
- Asynchronous background tasks.
- Responsive interface with **pt-BR and English support**.
- Dockerized full-stack environment.
- Interactive OpenAPI/Swagger documentation.
